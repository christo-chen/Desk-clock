# 桌面时钟 · Desk Clock

面向 iPhone 的全屏离线桌面时钟。TypeScript + Vite、原生 DOM 与手写 CSS，无前端框架、零运行时依赖。包含 6 种时钟、7 种独立动画、19 套日夜主题、15 款裁剪字体、36 条中英双语语录、10 个即时预览设置标签。界面默认中文、语录默认 English、纯粹主题、翻页卡片、翻页动画、24 小时制、显示秒、跟随系统外观、默认向左强制横屏。支持 Battery Status API 的浏览器还会在日期右侧显示电量图标。

**本次自测：SPEC v1.4，11 个文件、263 项 Vitest 测试通过；TypeScript、正式构建与 4 项原资源预算通过。** 已完成按位翻、主题清理和节日分类、辉光动画、整点轮转、自动切动画、数字渐变和万圣节/圣诞主题。全程只使用现有 node_modules，无联网、新增依赖或 Git 提交/推送。浏览器脚本已更新数量，本轮未运行；真实布局、光晕和触感仍需浏览器与 iPhone 验收。详细记录见 [自测记录](docs/self-test.md)。

## 本地运行

需要 Node.js 22.12+（或 24+）。首次安装依赖需要网络；本项目依赖已由用户安装，本轮构建与测试直接使用现有 node_modules。

```sh
npm install
npm run assets
npm run dev
```

用浏览器打开终端显示的地址。开发模式不安装 Service Worker；离线与更新流程应在生产预览或 HTTPS 部署站点检查。

```sh
npm test
npm run build
npm run preview
```

`npm run build` 依次裁剪字体、生成图标、执行 TypeScript 检查、构建 PWA，并打印和硬性检查 JS gzip ≤ 50 KB、CSS gzip ≤ 15 KB、字体合计 ≤ 150 KB、整个 dist ≤ 400 KB。预算按 1 KB = 1024 字节计算，整个 dist 的检查比仅统计预缓存更加保守；输出 `artifacts-budget.json`。字体、图标和许可证由脚本从免费 npm 包生成，不需要设计素材或联网字体 CDN。

WebKit 自测（安装浏览器需网络）：

```sh
npx playwright install webkit
npm run build
npm run test:browser
```

脚本输出 6 × 19 × 2 × 2 = 456 张时钟/主题/日夜/横竖屏截图至 `artifacts/screenshots/`，检查页面宽度、时钟边界、主界面节点数量，并检查语言切换、显示开关、主题/颜色/字体、语录添加编辑删除、设置持久化、35 种数字时钟/动画组合及离线重载。截图需要人工复核。可用 `TEST_URL=https://你的站点/ npm run test:browser` 测试部署网站。

## 部署到 GitHub Pages

1. 在 GitHub 新建空仓库（例如 `desk-clock`）。
2. 将本目录初始化为 Git 仓库，添加 GitHub 远程，并推送 `main`。本项目已由用户完成首次提交；后续修改可在项目终端提交，下面的初始化命令仅供新项目部署参考。
3. 在仓库 Settings → Pages，将 Source 设为 **GitHub Actions**。
4. Actions 安装依赖、运行 Vitest、构建并检查预算，然后发布静态站点。
5. 等待成功后打开 `https://用户名.github.io/仓库名/`。

```sh
# 若已有常规 Git 仓库，只需配置远程并推送。
git init -b main
git add .
git commit -m "Implement Desk Clock PWA"
git remote add origin https://github.com/你的用户名/desk-clock.git
git push -u origin main
```

工作流按仓库名自动设置 `BASE_PATH`；`用户名.github.io` 仓库使用 `/`，其他仓库使用 `/仓库名/`。本地默认相对路径 `./`。部署到其他子目录可用 `BASE_PATH=/clock/ npm run build`。备选：将 dist 上传到 Cloudflare Pages，免费 HTTPS 即可使用。

已采用本项目现有 `package-lock.json`，CI 使用 `npm ci` 固定依赖版本，随后测试、构建并检查预算。

## iPhone 安装与使用

推荐 iOS 18.4+（含 iOS 26）。iOS 16.4–18.3 可运行，屏幕常亮可能失效。启动时不申请常亮锁；第一次轻点屏幕时直接在点击事件中申请。状态只在「通用 → 屏幕常亮」下显示：已生效 / 等待轻点屏幕 / 不可用（不支持、系统拒绝或其他原因）。进入后台后释放，回到前台等待下一次轻点；主界面不弹常亮提示。低于 iOS 16.4 显示应用不支持提示。

1. 用 Safari 打开部署的 HTTPS 网址。
2. 点「分享 → 添加到主屏幕 → 添加」。
3. 从主屏幕图标打开，默认向左横放。即使 iPhone 开着旋转锁定，竖屏视口也会由应用整体旋转为横屏；在「通用 → 强制横屏」选择关闭后，竖屏数字分组恢复上下排列。

左上角临时切换日/夜，右上角打开设置，每次默认打开「主题皮肤」。右下角仅在竖屏视口且强制横屏开启时显示「旋转」弯曲箭头，点击在向左 / 向右横放之间切换，用 400 ms 平滑翻转整个界面 180°并保存。真正横屏或关闭强制横屏时不显示旋转按钮。按钮无操作 4 秒隐藏，轻点屏幕唤回。设置底部面板有默认档与约可用高度 90% 的展开档：上拉横条展开，下拉回默认，在默认档继续下拉关闭；轻点横条也能切档。松手按位置和速度吸附，同次打开保留档位，关闭再开回默认。内容纵向滚动，主题、时钟、字体卡片自动换行。支持 Escape 关闭及键盘 Tab / 左右键导航。更换主题会清除日夜自定义颜色并采用推荐字体，保留时钟类型；辉光管主题的动画自动选择规则见下文。

「通用」页的「强制横屏」提供关闭 / 向左横放 / 向右横放，默认向左横放。向左对应 `rotate(90deg)`，向右对应 `rotate(-90deg)`；只在视口高大于宽时启用，宽高互换后铺满可见区域。系统顶部安全区映射为应用左侧或右侧，内容避开状态栏、刘海和灵动岛。面板、提示和安装引导与应用一起旋转；面板沿应用自己的向下方向拖动关闭，而不是沿屏幕原始向下方向。此功能不改变系统的旋转锁定设置。

「显示」页有「显示电量」（默认开）与「显示电量百分比」（默认关）。支持 `navigator.getBattery()` 的浏览器在日期右侧显示小电池，填充跟随电量，充电显示闪电，低于 20% 且未充电时填充为红色。iPhone Safari 不支持此接口，整个组件不出现且不占位，系统状态栏照常显示自己的电量。开关仍可保存供支持该接口的设备使用。

「语录」页的「语录语言」独立选择 English / 中文，默认 English，不受界面或系统语言影响。36 条预设语录均有对应语言的作者/作品署名；自定义正文最多 120 字符，可选作者最多 40 字符，自定义内容始终保留原文。语录固定保留两行正文加一行署名的空间，关闭时淡出并隐藏；开关、长短、轮换和字号变化不会改变时钟位置。

v1.4 的 7 项迁移：

1. 翻页卡片左右数字独立翻动，仅变化位播放；两位同时变化延迟相同，组间仍从右向左间隔60ms。静止卡片和中线保持原样。
2. 删除时序局、水墨、王国；旧设置仅主题回落纯粹。浮世绘归文艺，古希腊归复古；筛选顺序为全部、极简、复古、科技、赛博朋克、自然、柔和、文艺、节日。15款字体全部保留。
3. 新增「辉光 / Glow」动画，位于无动画之前；各数字时钟原地换电极，带余辉、闪亮与光溢出。系统减弱动态效果时使用专用200/150ms版本，不显示溢出。
4. 动画页选择辉光后显示「整点轮转」，默认开。仅辉光管主题+辉光动画、非睡眠/非减弱动态/页面可见时触发。显示秒时在HH:00:00、不显示秒时在HH:00，逐位错峰快切9步，第10步回到实时时间，结束再次校准。
5. 选辉光管主题时自动切到辉光并记录autoGlow；离开主题时，自动选择的辉光恢复翻页。手动改过动画就保留用户选择。
6. 字体颜色页新增8个渐变预设与自定义顶部/底部（现有色板或HEX）。优先级为自定义渐变、自定义纯色、主题渐变、主题纯色。支持6种时钟、预览、像素/粒子、指针和渐变光晕；合成波/霓虹夜城/晨曦玫瑰有夜间默认渐变。逐端对比度不足3:1时提示，选纯色删除渐变。
7. 新增万圣节（黑橙、深暗角与胶片纸纹）和圣诞（松绿/奶油/红色、双层飘雪），共19主题/38日夜配色。雨雪都在主题动态特效关闭、睡眠、减弱动态或后台时暂停，保留静态纹理。

主题数据源为 [SPEC配色表](SPEC.md#72-配色表) 和 `scripts/gen-data.py` 的主题列表/渐变；修改源头后运行 `python3 scripts/gen-data.py`，不手改 `src/theme/themes.ts`。

睡眠模式默认关闭；开启后默认 23:00–07:00、3 秒调暗至 70%，可选夜视红，隐藏秒和语录并使用淡入淡出。睡眠时轻点可恢复正常显示 10 秒。日间/夜间自定义颜色各自保存。

全部设置和自定义语录只保存在本机 `deskclock:v1`，300 ms 防抖写入，容量不超过 8 KB。恢复默认会重置此应用设置。没有账号、统计脚本、网络校时、服务器数据存储或付费功能。首次在线加载完成后字体和代码会离线缓存；出现新版本时点提示更新。

## 调试参数

| 参数 | 功能 |
| --- | --- |
| `?speed=60` | 按 60 倍速度走时；范围 1–3600 |
| `?t=23:59:50` | 从本机日期的指定本地时间开始，用于跨午夜测试 |
| `?fps=1` | 左下角实时 FPS；仅调试时使用逐帧采样 |
| `?reset=1` | 恢复应用默认设置 |

可组合：`?speed=60&t=23:59:50&fps=1`。除调试起始时间/速度外，时间完全来自系统 Date.now()。手动时区使用 Intl 格式化，城市显示在日期末尾；系统时区变化在下一次刷新生效。

## 实现说明

未明确之处按简单、免费、美观、省资源决定如下：

- 时间、定时外观和睡眠以系统本地时间驱动；显示时区只影响时间/日期和每日语录。调试参数模拟整个时间源，不联网校时。
- 临时日夜切换不写入持久设置；系统外观变化或定时日/夜边界会清除临时覆盖。颜色页「正在编辑」选择同样属于临时预览。
- 跨午夜定时采用含开始、不含结束的区间；开始和结束相同视为全天。0 秒被关闭或睡眠隐藏后使用整分钟刷新；指针扫秒由 Web Animations 驱动，不用生产环境常驻 requestAnimationFrame。
- 轮换语录按系统时间的 N 分钟区块确定，每日语录按选定时区的日期确定；固定语录增加 `quote.fixed` 索引。空的「仅自定义」来源显示空白。更换语言不改变自定义文本。
- 语录用独立的 `quote.lang`，默认 English。正文最多两行，另保留署名一行；英文为“— 作者, 作品”，中文为“——作者《作品》”（沿用中文出处，苏格拉底按指定格式修正）。无作者时署名行留空。轮换采用 150 ms 淡出 + 150 ms 淡入。
- 时钟放在三行 Grid 的固定中间轨道，上下采用等分的 `minmax(0,1fr)`，底部内容大小不参与轨道最小高度计算。语录按当前字号保留两行正文加一行署名及 4px 间距；关闭只做 150ms 淡出后 `visibility:hidden`，节点始终存在。防烧屏原有的每分钟微移独立运行，验收语录位置时可先关闭防烧屏。
